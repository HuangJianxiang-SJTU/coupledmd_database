# Supplementary Data S8 — retrospectively inferred modeled segments

Primary table: 938 segments across 205 of 207 systems, replica 1 only. The complete unfiltered v2 population is used for all primary statistics. The frozen original CSV/JSON, computation scripts and checksum manifest are in revision_package/grafted_snapshot; they are preserved unchanged. Segment positions use the released PDB residue numbering and zero-based inferred chain_index, not source-PDB numbering.

Segments were inferred by difflib sequence comparison against experimentally resolved source-PDB chains, with autojunk disabled. The implemented mapping uses all exact matching blocks (not a minimum three-residue block); uncovered runs separated by up to three matched residues are merged, and isolated singletons are excluded. The 34,962-residue inferred mask includes 290 excluded singletons; the 938 analyzed segments contain 34,672 residues. Merged runs can include experimentally matched bridging residues. This is a retrospective comparison, not a manual graft log or proof of AlphaFold provenance. Construct changes, mutations, tags and use of GPCRdb-refined starting structures can affect identification.

RMSDs are in Å. Scaffold-fit RMSD uses resolved Cα atoms of the same chain when at least ten exist; six segments use the global resolved core. fit_scope and n_fit_ca document this choice. Self-fit RMSD removes each segment's rigid-body displacement. self_fit_low_atom_flag identifies two-residue segments, whose self-fit RMSD provides very limited information about conformation. The original self-fit values are retained for provenance. Neither metric proves experimental accuracy or absence of drift.

The analysis samples 225 replica-1 frames at 2-ns intervals from nominal 50 to 498 ns, relative to the production-start structure. The fixed 50-ns exclusion is descriptive and does not follow the system-specific S7 stationarity recommendation. No new PBC rejection or trend test was implemented in this v2 protocol. The script's header overstates removal of interdomain motion: fitting a chain removes overall chain motion but retains intrachain domain movement.

match_ratio is the difflib similarity ratio 2M/(N_sim+N_exp), not sequence identity among resolved residues. Added missing regions lower it even when resolved residues match perfectly. Gq_8F7X chain_index 0 has 351 simulated and 221 resolved residues; matching all 221 yields 0.773. It remains in the primary table. A blanket >=0.9 filter would retain 296/938 segments and substantially change the population. Sensitivity CSV/XLSX gives both that subset and the proposed exclusion of this chain, each with its own counts and summaries; neither replaces the full-population result. The inherited n_mutations column is a count of residue-name differences within matched sequence blocks, not a comprehensive mutation audit or an independent chain-quality score.

Resolved_controls contains 621 random resolved windows of length 6–15 residues (three per system). These windows use the same sampled frames and reference approach, with the selected window excluded from the fitting core. They are a descriptive comparison, not controls matched to every inferred segment by length, location or exposure. The original control output did not log window residue ranges or chain identifiers; retained source code and frozen results document the available provenance.
